# Call-path and dependency inspection

Skill: oma-backend. Source bytes and line counts: source-inventory.json. All observations below are implementation self-inspection, not independent QA.

- Cargo.toml adds one workspace member and one local dependency. arc-detector/Cargo.toml normal dependencies are only existing workspace Serde; serde_json is test-only. Cargo.lock adds the local crate and existing Serde/serde_json edges, with no registry version changes. The existing maintained Tokio, Clap, IPC and SQLite modules are reused.
- arc-detector/src/lib.rs:19 checks command byte size before scanning or shell selection; parser and aggregation share one AnalysisStats budget. Empty/unsupported/unknown results contain fixed enums. The aggregate function retains all effective leaves until it can select the first unresolved leaf, identical class or proven mixed locality.
- budget.rs:21 checks addition/overflow and refuses over-cap work before the operation. Lexer byte access and decoded byte copies charge first. UTF-8 validation reserves its full byte scan before calling the library. Equality checks reserve before accessing candidate bytes; library prefix/suffix/split/normalization operations reserve their bounded scans before running. Numeric IPv6 parsing uses explicit charged byte access and fixed-size numeric groups. No regex, shell parser service, filesystem discovery, endpoint probe, subprocess or environment lookup is used.
- parser.rs:55 validates depth before entering a scope. The parser uses bounded lookahead and append-only vectors, with no repeated front removal. Invocation nodes, token visits, nested wrappers and flattened leaves share counters. Nested literal inputs borrow decoded word storage. Unsupported constructs abort, rather than skip syntax to infer a class.
- types.rs contains closed Serde enums. ClassifyRequest denies unknown fields and explicit null shell kinds. Classification denies extra fields; is_consistent validates class/locality/reason/uncertainty combinations before the CLI prints peer-supplied results. No request or result includes an execution decision, job ID, permit, stage text or digest.
- arc-ipc/src/lib.rs:310 retains dispatch<F>(&Request, doctor:F)->Response. The existing version guard precedes the new operation. classify_response deserializes the typed payload, runs only the pure detector and constructs a four-field result; malformed payloads get fixed INVALID_REQUEST. No diagnostic snippets are returned.
- arc-daemon/src/connection.rs:95 routes classification before disposal, then nulls request.payload before any subsequent await. The response contains only typed enums plus the existing request envelope. No command enters DbWorker, SQLite, metrics, the runtime report or daemon logs. Authentication, admission, deadlines, lifecycle, worker, socket and report modules are unchanged.
- arc-cli/src/classify.rs:7 sends one literal command argument without normalization or shell evaluation. It contacts only the existing local Unix IPC endpoint. Before display it validates response protocol, request ID, status/error consistency, typed fields and semantic combinations. Remote messages never become error text. Its recovery text is fixed. main.rs sanitizes classification usage errors so Clap cannot echo unknown command operands; legacy status/doctor usage/errors and successful text are preserved.

Temporary memory remains necessary for protocol decoding and analysis. Drop/disposal is not secure memory erasure. The result describes syntax in this restricted subset, not actual PATH/alias selection, DNS topology or permission to execute. Behavioral traps and canary checks support these boundaries, with the required TCP monitor test explicitly unresolved due to environment denial.
